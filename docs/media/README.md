# Repository presentation assets

The hero and rating diagrams are self-contained SVGs: system fonts, no scripts, external resources or tracking. Each has a dedicated mobile composition selected by the README's picture element.

The rating diagrams are labelled illustrations with fictional values. They explain the existing assessment contract; they are not screenshots, live results, or a new product interface. The overall score is holistic and is not derived by averaging the dimension ratings.

Accessible titles/descriptions and equivalent README text preserve the meaning when the graphics are unavailable. The older dashboard screenshots remain under docs/screenshots and are labelled as fictional-data fixtures.
