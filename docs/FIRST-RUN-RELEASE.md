# First-run acceptance criteria

The friend milestone requires a person to use their own CV through the browser interface without editing JSON or issuing terminal commands during normal use. Setup and launch are provided as Windows scripts.

| Requirement | Current evidence | Remaining check |
| --- | --- | --- |
| Import, correct and confirm facts/preferences | Joined fictional browser journey; draft/revision/preservation tests; live Luna fictional text extraction | Friend's own document and corrections |
| Plan and search with six Luna missions | Joined fixture asserts routing; one live six-mission run completed | Wider role families and useful-result yield |
| Preliminary shortlist then selected full assessment | Joined fixture; one live preliminary recommendation assessed as a 48/100 stretch | Human calibration of recommendation quality |
| Generate and review exact CV before preparation | Connected fixture verifies current PDF hash and attachment identity | Bounded live Luna material check and exact-release verification |
| Confirm answers, resume same form, record outcome | Connected fixture verifies answer, retained attachment, prepared state and no submission | Varied employer forms with the human present |
| Shared limits and interrupted work | Atomic allowance/session/recovery regressions | Friend's actual account capacity and reset behavior |
| Download, setup and launch on Windows | Candidate ZIP built, audited, extracted and installed; launcher smoke passed | Full exact-artifact suite and published download readback |

Final Submit stays manual. Image-only CVs require readable text; unknown claims or commitments are not guessed. Scored, prepared and submitted are distinct states. Private data is excluded from the distribution.

See [current status](STATUS.md) and [release review](FRIEND-TEST-REVIEW.md) for the current evidence and outstanding gates. Historical development trials do not substitute for exact-release proof.
